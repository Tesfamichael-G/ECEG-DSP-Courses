# MSc DSP Courses

**ECEG-6303 — Advanced Digital Signal Processing**  
**ECEG-6423 — Multimedia Signal Processing**

Two course sites for the **MSc in Communication Engineering** DSP track.
Each has lecture notes, worked examples, code, quizzes, solutions, and an
exam bank.

---

## The DSP track

<div class="grid cards" markdown>

- :material-waveform: **ECEG-6303 — Advanced DSP**

    ---

    **Semester I · Compulsory Core**

    Extends the classical DSP sequence into statistical and adaptive signal
    processing. Discrete random signals, spectrum estimation, linear
    estimation and prediction, adaptive filters (LMS, RLS), and multirate
    DSP.

    [:octicons-arrow-right-24: ECEG-6303](ecg-6303/index.md)

- :material-image-multiple: **ECEG-6423 — Multimedia Signal Processing**

    ---

    **Semester II · Elective II**

    Applies DSP to the three pillars of multimedia: **images**, **speech**,
    and **video**. Image transforms, enhancement, restoration, compression;
    speech analysis, recognition, synthesis; video coding and streaming.

    [:octicons-arrow-right-24: ECEG-6423](ecg-6423/index.md)

</div>

## What's in each course

Every course site contains the same structure, so you always know where to look:

<div class="grid cards" markdown>

- :material-book-open-variant: **Chapters**

    ---

    Full lecture notes with numbered worked examples, computational
    implementations in **Python / Java / C#**, and chapter summaries.

- :material-lightbulb-on: **Solutions**

    ---

    Key steps and final answers for the tutorial problems at the end of
    every chapter.

- :material-clipboard-check: **Exam bank**

    ---

    answer key and instructor grading rubric.

    ---

    rules.

## About this site

This site is the **rendered, canonical version** of the DSP course material.
It is built from Markdown source files using **MkDocs** and the **Material
for MkDocs** theme, and published automatically from
[GitHub](https://github.com/tesfamichael-g/ECEG-DSP-Courses) via GitHub
Actions.

The Markdown source is also public, but **it does not render well on
github.com** — MathJax equations, Material icons, admonitions, and grid
cards are all shown as literal text. Use this site for the actual content;
the source repository is for contributors and maintainers.

## Programme context

These two courses are part of the **MSc in Communication Engineering**
programme, which includes several other courses (optimization and stochastic
processes, communication systems, networks, and more). A **centralized
programme hub** listing all MSc course sites is planned. Until it exists,
this site serves only the DSP track — no cross-links to the other courses
are provided here.
