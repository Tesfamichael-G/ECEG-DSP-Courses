    MSc DSP Courses¶

    ECEG-6303 — Advanced Digital Signal Processing
    ECEG-6423 — Multimedia Signal Processing

    Two course sites for the MSc in Communication Engineering DSP track. Each has lecture notes, worked examples, code, quizzes, solutions, and an exam bank.

    The DSP track¶

    • ECEG-6303 — Advanced DSP

      Semester I · Compulsory Core

      Extends the classical DSP sequence into statistical and adaptive signal processing. Discrete random signals, spectrum estimation, linear estimation and prediction, adaptive filters (LMS, RLS), and multirate DSP.

      ECEG-6303

    • ECEG-6423 — Multimedia Signal Processing

      Semester II · Elective II

      Applies DSP to the three pillars of multimedia: images, speech, and video. Image transforms, enhancement, restoration, compression; speech analysis, recognition, synthesis; video coding and streaming.

      ECEG-6423

    What's in each course¶

    Every course site contains the same structure, so you always know where to look:

    • Chapters

      Full lecture notes with numbered worked examples, computational implementations in Python / Java / C#, and chapter summaries.

    • Solutions

      Key steps and final answers for the tutorial problems at the end of every chapter.

    • Exam bank

      100 marks of exam-style questions (MCQ, short answer, derivation) with answer key and instructor grading rubric.

    • Schedule & assessment

      Week-by-week plan, assessment weighting, grading policies, submission rules.

    Shared resources¶

    These pages apply to both ECEG-6303 and ECEG-6423 — they are the common reference for notation, formulas, and software.

    • DSP Primer

      Notation conventions, Fourier / Z / Laplace transforms, sampling theorem, transform pairs, key theorems, filter design, random-signal definitions. Referenced by both courses.

      DSP Primer

    • Software setup

      Python environment, MATLAB toolboxes, Java / C# libraries, Jupyter, IDE recommendations, common installation issues, and a quick environment test.

    • References

      Common DSP textbook shelf, free online books, video lectures, key papers, and tool documentation — organised by topic.

    About this site¶

    This site is the rendered, canonical version of the DSP course material. It is built from Markdown source files using MkDocs and the Material for MkDocs theme, and published automatically from GitHub via GitHub Actions.

    The Markdown source is also public, but it does not render well on github.com — MathJax equations, Material icons, admonitions, and grid cards are all shown as literal text. Use this site for the actual content; the source repository is for contributors and maintainers.

    Programme context¶

    These two courses are part of the MSc in Communication Engineering programme, which includes several other courses (optimization and stochastic processes, communication systems, networks, and more). A centralized programme hub listing all MSc course sites is planned. Until it exists, this site serves only the DSP track — no cross-links to the other courses are provided here.
